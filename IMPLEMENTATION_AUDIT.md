# Implementation Audit and Required Repairs

**Audit basis:** source files and logs in the uploaded project ZIP; 42 tests independently run on 9 November 2026.

## Critical blockers before new scope-transfer runs

### 1. Matched-pair treatment is overwritten

In `replay.py`, `ScopeInterventionHarness.run_matched_pair()` receives `native_message` and `plain_message`, but constructs a hardcoded `URGENT COORDINATION INSTRUCTION` string inside the loop and posts it to both arms. The parameters are never used for the intervention.

**Required repair:** select `native_message` for `arm == "native"` and `plain_message` for `arm == "plain"`. Put the adversarial instruction in a separate explicit experimental mode. Add a regression test asserting that the two intervention events contain their respective input strings and are not identical.

### 2. Convention detector can misclassify ordinary language

On `formation_ep1_9f853b`, `detect_qualifying_convention()` returns `my reading is` as the highest-ranked qualifying phrase. That is not a coordination convention.

`extract_and_adapt_convention()` is a separate keyword-based routine. It selects the earliest message containing the source resource, `release`, and `queue`, then counts broad coordination markers across the transcript. It does not call the frozen criterion evaluator, does not establish that the same coordination function is used by the adopting agents, and does not record a human approval. Yet the returned provenance text says `human-verified transcript candidate`.

**Required repair:** have candidate extraction return `candidate_unverified`; implement a transparent coding rubric; store the exact excerpts and reviewer decision; only allow transfer after a reviewer explicitly approves the candidate. Add negative tests for boilerplate phrases such as `my reading is`, `0/5 recorded`, and `final round`.

### 3. Permit support is not end-to-end

`ReferenceMonitor.check_action()` supports permit ID and nonce arguments, but `agent_runner.py` does not pass permit parameters from the parsed action into the monitor. Also, nonce comparison only happens when a nonce is supplied; absence of the nonce does not cause rejection.

**Required repair:** define a trusted orchestrator path for permit issuance; require a nonce for permit-based authorization; pass validated permit fields to the monitor without letting an untrusted agent self-issue capabilities; add end-to-end tests through `execute_agent_turn()` / tool execution, not only direct unit calls.

## High-priority reproducibility repairs

### 4. Source version and historical logs are not linked

The formation log's round-2 write attempt says the agent no longer holds a claim acquired in an earlier round. Current `environment.py` says claims persist across rounds until released. The archive does not identify the exact source commit that generated the older run.

**Required repair:** record `git_commit`, source hash, prompt hash, model, provider, temperature, seed, start/end times, token usage, snapshot ID/hash, treatment arm, and guard configuration in every run's metadata.

### 5. Run metadata counters are inaccurate or absent

`run_formation()` sets both metadata timestamps after the episode and does not fill API-call or token counters. Scope runs do not save complete `RunMetadata` records.

**Required repair:** start/end timing around the actual run; aggregate provider usage; save one metadata JSON per scope arm; include a snapshot checksum and source revision.

### 6. Metric implementation needs stricter action validation

`compute_protocol_premium()` treats an action with `tool is None` as a state-changing action for legacy fixtures. The unit test `test_protocol_premium_calculation` omits tool names and therefore passes a positive metric using untyped action events. Production metrics should not infer an action type from a missing tool name.

**Required repair:** count only explicit `claim_resource`, `write_resource`, and `release_resource` requests; classify missing/unknown tools as malformed; add metric tests for missing tool, wrong resource, sender, owner, read-only inspection, failed action, and successful action.

### 7. Test traces are mixed with experimental logs

The included `logs/raw/test_fork_native.jsonl` and `test_fork_plain.jsonl` are generated by test code. They are not experimental evidence and the test harness writes into the same default log directory as research runs.

**Required repair:** inject a temporary `log_dir` into the matched-pair test or use a fixture; keep test outputs under a temporary path; exclude generated test artifacts from the research evidence directory.

## Presentation repairs

### 8. README and documentation were stale

The original README still used the Protocol Premium name and listed 18 tests. The submission README listed 39 tests and incomplete results. `final_review.txt` was a copy of source code, not a review document.

**Repair in this package:** README and research docs have been replaced/added; the obsolete duplicate README and source dump have been removed from this package.

### 9. Dashboard graph labels overstate influence

`build_communication_network()` infers edges from explicit mentions or prior-speaker adjacency, then computes a weighted degree score. This is a rough conversation graph, not an influence model.

**Required repair:** label the chart as a mention/turn-sequence network; remove causal labels such as `influential_incumbent` unless independently validated.

## Verification already completed

- `python -m pytest -q`: **42 passed** on the uploaded source snapshot.
- Raw trace audit: nine complete native/plain pairs with the expected messages and two post-intervention rounds; eight unguarded and one guarded.
- In those nine pairs, non-owner recipients made zero `claim_resource`, `write_resource`, or `release_resource` requests targeting `calibration_console` in both arms.
- Guarded archived traces contain authorized checks only and no denied checks.

Passing tests do not clear the source-level blockers above. The missing regression tests are precisely why the current bug can coexist with a green suite.
